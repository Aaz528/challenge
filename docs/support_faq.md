# FAQ: поддержка пользователей

## Почему не работает авторизация?

- Проверьте, не истёк ли access token и не используется ли старый refresh token после смены пароля.
- Для ошибки `invalid_token` попросите пользователя выйти из всех сессий и повторно войти.
- Уточните платформу и версию клиента: на старых клиентах может быть несовместимость после обновления backend-auth.

## Что делать, если после оплаты план не обновился?

- Проверьте, что webhook от платёжного провайдера доставлен и обработан без ошибок.
- Сверьте идентификатор пользователя в платёжной системе и в локальной БД.
- Если платёж подтверждён, а план не обновился, выполните ручной reconcile по конкретному user_id.

## Какие данные обязательно запросить у пользователя в тикете?

- user_id (или email)
- ticket_id
- платформа (web/ios/android)
- версия приложения
- точный текст ошибки или код
